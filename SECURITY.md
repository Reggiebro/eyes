# Security policy

## Private reports

Use GitHub's **Report a vulnerability** on the repository's [Security page](https://github.com/ayaangazali/eyes/security/advisories/new).
Do not publish vulnerabilities, credentials, or personal data in issues or pull requests.

Private vulnerability reporting was disabled when checked on 2026-10-20.
If the report button is unavailable, do not post the details publicly.
Ask the maintainer to enable private reporting before sending details through GitHub.

Include the affected version or commit, reproduction steps, expected impact, and a minimal example without real credentials or personal data.

## Scope

This policy covers Eyes code: the MCP and REST APIs, OAuth, payments, and worker flows.
Report faults in third-party services to their providers.
Test only accounts and data that you control; do not disrupt other users or move real funds.

The project offers no bug bounty.
