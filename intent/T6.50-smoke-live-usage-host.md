## Why

Production is Cloudflare Containers behind the `eyes-api` Worker at https://api.eyes.pictures. A reader copying the hint would smoke-test a host that is no longer production.

## What changed

- `scripts/smoke-live.ts`: the usage message example host goes from `dark-wave-wfmpm.run.mcp-use.com` to `api.eyes.pictures`. No logic change.
- `scripts/smoke-live.test.ts` keeps its sample text with the old host. It is parser input, not a claim about the current server.
