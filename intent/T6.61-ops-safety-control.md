## Why
Operators adjust the classifier blocking confidence without changing the fixed privacy rules. A compact Overview card reuses the dashboard's surfaces, typography, spacing and request helper. The native labelled slider accepts 0.50 through 1.00 in 0.01 steps. Higher is more permissive; 1.00 is not off.

## Contract and behavior
GET and PUT `/ops/api/settings` return `{classifier_block_min, default, updated_at, updated_by}`; PUT sends only `{classifier_block_min}`. The existing host-relative request helper preserves same-origin session and CSRF/Origin protections. Only GET 404 hides the card during rollout. Other load failures offer Retry; failed saves retain the draft. Controls lock during save, success uses the returned value, and reload fetches the persisted value. Server and classifier implementation belong to the backend task.

## Verification
Behavioral page tests cover loading a non-default value, bounds, invalid values, duplicate-save prevention, pending/success/error states, retry, persisted reload and old-API hiding. Rendered Overview is checked with controlled, fictional API data at 390 and 1440 pixels in light and dark modes. No new dependencies or presets are needed: the exact threshold remains visible beside the slider.
