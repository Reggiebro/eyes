## Why

Documentation-only pull requests should skip heavyweight checks without skipping intent validation or secret scanning. Failed GitHub lookups must not report successful auto-merge cleanup, and an older run must not enable merge for a newer untested head.

## What changed

- Limit the lightweight path to root Markdown, Markdown under docs/ and intent/, and LICENSE. Executable files, symlinks, app Markdown, and renamed source files retain code checks.
- Keep intent and secret scanning mandatory before enabling docs auto-merge. Check the current head, draft flag, and open state, then pass the tested head to GitHub's merge command without bypassing branch requirements.
- Fail cleanup when both disabling auto-merge and querying its state fail. Only a successful response confirming no auto-merge request is harmless.
- Exercise the actual workflow shell from the scope tests, including classification, failed diffs, failed GitHub queries, and stale heads.
